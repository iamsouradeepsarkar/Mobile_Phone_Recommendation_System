# AI-Based Mobile Recommendation System

An AI-based mobile recommendation system that helps users choose a mobile phone based on their requirements such as budget, camera quality, RAM, screen size and so on. The project uses a cleaned mobile dataset, computes rankings for brands/models/processors, and then uses a Ollama-based AI model ([gpt-oss:120b](https://ollama.com/library/gpt-oss:120b)) to interpret user preferences and explain the final recommendation.

## Overview

This project combines:

- Data cleaning and transformation of a mobile phone dataset consisting of nearly 1000 mobile phones
- Rating generation for unique companies, models, and processors which will be used in the recommendation process
- User input validation and extraction of technical requirements through an AI model
- Filtering and scoring of mobile phones against the user's needs
- Final recommendation and explanation generated through an AI model

The application is intended to run locally on your machine without requiring a cloud-based API.

## Features

- AI-assisted parsing of user requirements from natural language input
- Dataset refinement for mobile specifications such as RAM, camera, storage, battery, price, launch year etc
- Brand, model, and processor scoring based on dataset-derived rankings
- Filtering of devices that match important constraints
- Ranking of the best matches according to user priorities
- Recommendation explanation generated by an AI model

## Tech Stack

- Python 3.x
- Pandas
- Ollama

- CSV-based mobile dataset

## Prerequisites

1. Before running the project, make sure you have the following installed:

- Python 3.9 or newer
- pip
- Git
- Ollama installed and running locally

2. You will also need the model used by the application:

```bash
ollama pull gpt-oss:120b-cloud
```

If Ollama is not installed yet, install it from:

https://ollama.com/download

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd Mobile_Phone_Recommendation_System
```

2. Create and activate a virtual environment:

On Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

On macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Confirm Ollama is available:

```bash
ollama list
```

If the model is missing, pull it:

```bash
ollama pull gpt-oss:120b-cloud
```

## Usage

Run the application from the project root:

```bash
python src/main.py
```

You will be prompted to describe the type of mobile phone you want. Example inputs:

```text
I want a phone under 30000 rupees with at least 6GB RAM, a good camera, and long battery life.
```

```text
I need a phone with 128GB storage, 8GB RAM, AMOLED screen, and a fast processor under 45000.
```

```text
Recommend a lightweight phone with a strong battery, good front camera, and a mid-range price.
```

The program will:

1. Validate your query
2. Extract important requirements from it
3. Clean and refine the mobile dataset if needed
4. Generate company, model, and processor rankings
5. Filter mobile phones based on your constraints
6. Rank the best options by score
7. Print the recommended phone and explain why it fits your request

## How It Works

### 1. Data cleaning
The script in `src/data_cleaner.py` reads the raw dataset, removes unnecessary columns, normalizes values, and writes a refined CSV file into the `refined_mobile_data` folder.

### 2. Rating generation
The project calculates separate ratings for unique:

- companies
- models
- processors

These JSON files are stored in the `ratings_files` directory and used during final scoring.

### 3. Requirement extraction
The AI layer uses prompt instructions from the `instructions` folder to:

- validate whether the user input is meaningful and complete
- extract features and preferences from the natural-language query

### 4. Filtering and scoring
The logic in `src/filter_mobiles_based_on_user_inputs.py`:

- filters devices by strict constraints such as RAM, camera, price, battery, and screen size
- assigns weighted scores based on user priorities
- sorts the remaining devices by overall compatibility

### 5. Recommendation output
The final recommendation is displayed in the console, and the system explains why the selected phone is the best choice for the requested use case.

## Important Notes

- The application uses a local Ollama model (`gpt-oss:120b-cloud`) for AI validation and explanation.
- You must have Ollama running in order for the recommendation flow to work.
- The project relies on the dataset file being available in the expected location. If the folder name or file path differs, update the path used in the Python files accordingly.
- The repository currently includes generated files in `refined_mobile_data` and `ratings_files`; these will be regenerated automatically when these files aren't present by default.
